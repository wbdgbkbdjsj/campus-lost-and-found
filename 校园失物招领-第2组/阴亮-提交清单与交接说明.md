## 3 全组口径速查（发群用，别再各写各的）

> **约定的唯一出处是 `03_六份交付材料/全组约定与编号总则-v1.md`**：编号空间、效力优先级、变更四步法、提交命名都在那里。本节只是发群用的速查摘抄，冲突时以总则为准。

| 项          | 唯一正确写法                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 三端         | A 学生端 / B 审核端 / C 后台管理端，**单工程 + RBAC**，不是三个工程                                                                                            |
| 三角色        | `student` / `reviewer` / `super_admin`；`admin`、`user`、`auditor` 一律废弃                                                                     |
| 表          | 9 张：`user` `category` `location` `lost_item` `found_item` `claim` `review_record` `notification` `audit_log`                             |
| 认领单 8 态    | `SUBMITTED` `UNDER_REVIEW` `PENDING_INFO` `APPROVED` `REJECTED` `CANCELLED` `COMPLETED` `EXPIRED`（12 条合法迁移、4 个终态封闭）                      |
| 物品 5 态     | `REGISTERED` → `CLAIMING` → `PICKUP_PENDING` → `CLAIMED`，旁路 `CLOSED`；驳回 / 撤销 / 超期回退 `REGISTERED`                                         |
| **身份核验顺序** | **提交 → 接单(#18) → 审核通过(#20) → 身份核验(#19，`APPROVED` 自环、不改状态、写 `VERIFY` 流水) → 交接(#23)**                                                      |
| I7         | 交接前必须存在 VERIFY 通过流水，否则返回 `40003`；I6 = 审核动作限已接单 reviewer 本人                                                                               |
| 接口         | 30 条，按 A/B/C 三端分组；错误码 `40001` 非法迁移 / `40002` 越权 / `40003` 参数或前置不满足 / `40101` 未登录                                                         |
| 技术栈        | 正式口径 `Vue3 + Spring Boot 3 + MyBatis-Plus + MySQL 8 + Nginx`；`FastAPI + SQLAlchemy + SQLite` 只作**审核状态流原型 / 演示保底 / 测试素材**，写进附录可，不能当正文技术选型 |
| 演示         | 金道轩《演示脚本-v0.md》§2「15 步主表」，现场 7 步映射见其 §3；步 11 通过、步 12 核验、步 13 交接                                                                          |
