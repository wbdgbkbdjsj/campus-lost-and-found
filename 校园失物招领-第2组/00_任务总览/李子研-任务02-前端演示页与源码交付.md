## 2 联调要改的具体点（★照表改，别凭感觉）

邓的工程是按 **v0 假设**写的，和契约 v1 / FastAPI 实际返回**对不上**。逐项如下：

| # | 文件 | 现在（v0 假设） | 改成（v1 实际） |
|---|---|---|---|
| 1 | `vite.config.ts` | `proxy['/api'].target = 'http://localhost:8080'`，无 rewrite | `target: 'http://127.0.0.1:8000'`，并加 `rewrite: (p) => p.replace(/^\/api/, '/api/v1')` |
| 2 | `src/utils/request.ts` | `if (body.code !== 200)` 判错；`code === 401` 跳登录 | **成功码是 `0`**，改成 `!== 0`；未登录是 `40101`；错误提示优先取 `body.detail`，回退 `body.message` |
| 3 | `src/utils/constants.ts` | `ROLE_STUDENT='STUDENT'` / `AUDITOR` / `ADMIN` | **`student` / `reviewer` / `super_admin`**；`ROLE_HOME` 的路由值不变；`ROLE_LABEL` 的「管理员」改「超级管理员」；删掉 `TODO(契约 v0)`，按契约 v1 补 8 态 / 5 态枚举 |
| 4 | `src/router/modules/{student,audit,admin}.ts` | `STUDENT_ROLE='STUDENT'` 等三个大写常量 | 改为引用 `constants.ts` 里的小写角色码，**不要三处各写一份** |
| 5 | `src/api/auth.ts` | `LoginPayload { username, password }`；`GET /auth/profile`；`POST /auth/logout` | `{ student_no, password }`；`GET /auth/me`；**原型无 logout 接口**，前端只清 `localStorage` 即可 |
| 6 | `src/types/index.ts` | `LoginUser { id, username, nickname, role, avatar? }` | `{ id, student_no, name, role }`；`ApiResult` 保持 `{code,message,data}`，另可加可选 `detail` |
| 7 | `src/stores/auth.ts` | `displayName` 取 `nickname \|\| username` | 取 `name \|\| student_no` |
| 8 | `src/types/business.ts` | 契约 v0 的实体/状态占位 | 按 `api-contract-v1.md` §2/§5 重写：9 张表、认领单 8 态、物品 5 态 |

**第 2 项是最要命的一处**：现在 `body.code !== 200` 会把 FastAPI 所有 `code: 0` 的成功响应全判成失败并弹错误提示，不改这一个判断，后面全白做。

**后端事实**（照实调，别猜）：
```
前缀 /api/v1（已由 vite rewrite 处理）  统一响应 { code, message, data }
登录 POST /auth/login { student_no, password } → data.token + data.user{ id, student_no, name, role }
之后每请求带 Authorization: Bearer <token>
错误码 40001 非法迁移 / 40002 越权 / 40003 参数或前置不满足 / 40101 未登录 / 40401 不存在
种子账号 reviewer001 / stu001 / stu002 / super001，口令均 123456
claim 详情返回 status / status_text / allowed_events / records
```

> 顺带把邓昌兴那几份 md 里的 v0 口径一起改掉（角色码、`api-contract-v0.md` 引用）——反正你联调时必须动 `constants.ts`，一次改干净，别留两套。
