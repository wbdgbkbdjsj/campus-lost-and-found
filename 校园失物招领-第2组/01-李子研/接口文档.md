# 接口文档 — 校园失物招领与认领审核系统 v1.0

> 基于 `api-contract-v0.md` 冻结契约细化字段级定义。Base URL：`http://127.0.0.1:8000/api/v1`
> 统一返回：`{"code":0,"message":"ok","data":{}}`；失败 `{"code":40001,"message":"ILLEGAL_TRANSITION","detail":"..."}`
> 鉴权：除登录/注册外，均需请求头 `Authorization: Bearer <token>`

## 0. 枚举速查

| claim.status | 中文 | 可执行事件 |
|---|---|---|
| SUBMITTED | 待审核 | ACCEPT(管理员) / REJECT(管理员) / CANCEL(申请人) |
| UNDER_REVIEW | 审核中 | APPROVE / REJECT / REQUEST_INFO / CANCEL |
| PENDING_INFO | 待补充材料 | RESUBMIT(申请人) / CANCEL / EXPIRE(系统) |
| APPROVED | 审核通过·待领取 | HANDOVER / EXPIRE(系统) |
| REJECTED | 已驳回 | — 终态 |
| CANCELLED | 已撤销 | — 终态 |
| COMPLETED | 已完成 | — 终态 |
| EXPIRED | 已失效 | — 终态 |

## 1. 认证

### POST /auth/login
请求：
```json
{ "student_no": "2021001", "password": "123456" }
```
响应：
```json
{ "code": 0, "message": "ok",
  "data": { "token": "3f2a...", "user": { "id": 1, "student_no": "2021001", "name": "王小明", "role": "user" } } }
```

错误：40101 学号或口令错误。

响应 data：`{ "id":1, "student_no":"...", "name":"...", "role":"user" }`

## 3. 认领申请（A 端 + 共用）

### POST /claims
请求：
```json
{ "found_item_id": 12, "description": "11月1日上午在三教201丢的黑色长柄伞",
  "proof": "伞柄有一道白色划痕，伞骨内侧写有姓名缩写 WXM", "contact": "138****0000" }
```
响应 data：
```json
{ "id": 8, "found_item_id": 12, "applicant_id": 1, "status": "SUBMITTED",
  "submitted_at": "2026-11-04 10:12:00", "deadline": null, "reviewer_id": null }
```
前置校验：
- 物品须存在且 status ∈ {REGISTERED, CLAIMING}，否则 40003。
- 同一申请人对同一物品不得存在未终结的认领单（SUBMITTED/UNDER_REVIEW/PENDING_INFO/APPROVED），否则 40003。
- 提交成功后 found_item.status → CLAIMING。

### GET /claims?scope=mine
响应 data：
```json
{ "total": 2, "items": [ { "id": 8, "status": "UNDER_REVIEW", "title": "黑色雨伞", "updated_at": "2026-11-04 10:20:00" } ] }
```

### GET /claims/{id}
响应 data 含审核历史：
```json
{ "id": 8, "status": "PENDING_INFO", "deadline": "2026-11-11 10:20:00",
  "records": [
    { "action": "ACCEPT", "from_status": "SUBMITTED", "to_status": "UNDER_REVIEW",
      "reviewer_id": 2, "comment": "", "created_at": "2026-11-04 10:20:00" },
    { "action": "REQUEST_INFO", "from_status": "UNDER_REVIEW", "to_status": "PENDING_INFO",
      "reviewer_id": 2, "comment": "请补充物品内部特征", "created_at": "2026-11-04 10:25:00" }
  ] }
```
权限：申请人本人或管理员，否则 40002。

### POST /claims/{id}/supplement
```json
{ "proof": "伞骨内侧姓名缩写 WXM，另附伞面破损照片一张" }
```
规则：状态必须为 PENDING_INFO，事件 RESUBMIT → UNDER_REVIEW；proof 非空否则 40003。

## 4. 审核 B 端（核心）

### GET /review/queue
请求头需 admin。响应 data：
```json
{ "total": 2, "items": [
  { "id": 8, "title": "黑色雨伞", "applicant": "王小明", "proof": "...",
    "status": "SUBMITTED", "submitted_at": "2026-11-04 10:12:00", "waiting_minutes": 35 } ] }
```
排序：submitted_at 升序（先到先审）。

### POST /review/claims/{id}/accept
请求：无 body（或 `{"comment":"我处理"}`）
响应 data：`{ "id":8, "status":"UNDER_REVIEW", "reviewer_id":2, "updated_at":"..." }`

| 错误 | 场景 |
|---|---|
| 40001 | 当前非 SUBMITTED（已被他人接单/已终态） |
| 40002 | 非 admin |
| 40401 | 单据不存在 |

### POST /review/claims/{id}/approve
请求：`{ "comment": "凭证与物品特征一致，同意认领" }`
响应 data：`{ "id":8, "status":"APPROVED", "deadline":"2026-11-11 11:00:00" }`
伴随：found_item.status=PICKUP_PENDING，发通知"审核通过，请 7 日内到 B12 柜领取"。
约束：仅 reviewer_id=当前管理员，否则 40002；状态必须 UNDER_REVIEW，否则 40001。

### POST /review/claims/{id}/reject
请求：`{ "comment": "凭证描述与物品明显不符（颜色不同）" }`  ← comment 必填
响应 data：`{ "id":8, "status":"REJECTED" }`
约束：状态 ∈ {SUBMITTED, UNDER_REVIEW}；comment 空 → 40003。

### POST /review/claims/{id}/request-info
请求：`{ "comment": "请补充物品内部特征" }`  ← comment 必填
响应 data：`{ "id":8, "status":"PENDING_INFO", "deadline":"2026-11-11 11:30:00" }`

### POST /review/claims/{id}/handover
请求：`{ "comment": "已核验学号与凭证，现场交接" }`
响应 data：`{ "id":8, "status":"COMPLETED" }`
伴随：found_item.status=CLAIMED，通知双方。

### POST /review/claims/{id}/cancel   （申请人撤销，也走审核模块统一入口）
请求：`{ "comment": "已在别处找到" }`
响应 data：`{ "id":8, "status":"CANCELLED" }`
约束：仅申请人本人；状态非终态；APPROVED 撤销后 found_item 回退 REGISTERED。

### POST /review/expire-run
请求：无 body（或 `{"now":"2026-11-20T00:00:00"}` 便于测试）
响应 data：
```json
{ "expired": 2, "ids": [8, 9] }
```
规则：PENDING_INFO 超 deadline → EXPIRED；APPROVED 超 deadline → EXPIRED 且 found_item 回退 REGISTERED。

### 错误码总表
| code | message | detail 示例 |
|---|---|---|
| 40001 | ILLEGAL_TRANSITION | REJECTED 不允许事件 APPROVE |
| 40002 | FORBIDDEN | 该单据已由审核员#2 接单 |
| 40003 | VALIDATION_ERROR | 驳回必须填写原因 |
| 40401 | NOT_FOUND | claim#99 不存在 |
| 40101 | UNAUTHORIZED | token 无效或已过期 |

## 6. curl 快速验证

```bash
# 1 登录（种子数据：审核员 admin001/123456，用户 stu001/123456）
curl -s -X POST http://127.0.0.1:8000/api/v1/auth/login \
  -H "Content-Type: application/json" -d '{"student_no":"admin001","password":"123456"}'

# 2 待审核队列
curl -s http://127.0.0.1:8000/api/v1/review/queue -H "Authorization: Bearer <ADMIN_TOKEN>"

# 3 接单 → 通过 → 交接
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/accept  -H "Authorization: Bearer <ADMIN_TOKEN>"
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/approve -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" -d '{"comment":"凭证一致"}'
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/handover -H "Authorization: Bearer <ADMIN_TOKEN>"

# 4 非法迁移验证（应返回 40001）
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/approve -H "Authorization: Bearer <ADMIN_TOKEN>"
```
