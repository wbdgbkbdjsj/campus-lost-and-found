## 2　测试策略（三层组织）

按指导书要求分**单元 / 集成 / 确认**三层，每层写清「测什么 / 怎么测 / 证据在哪 / 结论」。三层互不顶替：冒烟主链属于**确认测试**，不能拿它冒充单元测试。

### 2.1 单元测试（Unit Test）

| 项 | 内容 |
| --- | --- |
| 被测单元 | `state_machine.py` 状态迁移纯函数；`service.py` 中的权限判定与不变量校验；枚举/字典常量 |
| 测试隔离 | 不启 HTTP、不连数据库，直接调函数；输入 = (当前状态, 事件, 上下文)，断言 = (目标状态 或 抛出的错误码) |
| 用例来源 | 契约 v1 §4 的 8 态 12 条合法迁移全表 + 终态封闭 + I1–I7 |
| 已实跑证据 | 冒烟输出「终态封闭与非法迁移」3 项：`重复通过(应40001)`、`已完成单撤销(应40001)`、`不存在单据(应40401)`；`退缺 comment(应40003)` |
| 结论 | 终态封闭、错误码、必填校验 **4 项实跑通过**；8 态×事件组合的完整单元测试集为 `测试用例表.md` TC-ST-01~13 等 **设计用例，尚未逐条独立执行**，不写作通过 |

**单元测试典型断言（可直接引用）**：

```
TC-ST-01  COMPLETED + APPROVE  -> 40001「终态不允许事件」（实跑通过）
TC-ST-02  COMPLETED + CANCEL   -> 40001「终态不允许事件」（实跑通过）
TC-ST-03  UNDER_REVIEW + RETURN(comment 为空) -> 40003（实跑通过）
TC-ST-04  APPROVED + HANDOVER 且无 VERIFY 流水 -> 40003 I7（实跑通过）
TC-ST-05  APPROVED + VERIFY -> APPROVED 自环、状态不变、写 VERIFY 流水（实跑通过）
```

### 2.2 集成测试（Integration Test）

| 项 | 内容 |
| --- | --- |
| 被测链路 | `Router → Service（事务边界）→ StateMachine → ORM → SQLite`，验证跨层数据一致性 |
| 关键断言 | 每次状态变更同时落 **两张表**（`claim` + `found_item`）与 **一条流水**（`review_record`），防止「接口返回成功但数据没落」 |
| 接口数 | 契约 v1 共 30 条，原型已实现 24 条；本次覆盖 24 条中的主链与越权分支（含 C 端 #25–30） |

| 越权集成 | `学生访问队列(应40002)`、`超管访问队列(应40002)` 实跑通过，验证 RBAC 三角色在接口层生效 |
| C 端集成（本次新增验证） | `super001` 登录后调 `/api/v1/admin/*` 全接口 200；`stu001` 越权调管理接口返回 `40002`；管理员停自己账号返回 `40003`；认领单 CSV 导出正常（utf-8-sig，Excel 可读） |
| 结论 | **主链 24 项断言实跑通过、失败 0 项**（两次独立复现：李子研 17:05、组长 21:41）；C 端 #25–30 后台管理接口已在原型实现并验证，管理员权限最多、越权被拦截，符合契约 v1 |

**数据一致性证据（贴冒烟第 6 节原文）**：

```
SUBMITTED     --ACCEPT--> UNDER_REVIEW
UNDER_REVIEW  --APPROVE--> APPROVED      | 凭证与物品一致
APPROVED      --VERIFY--> APPROVED       | 核验不通过：到场人与申请人不一致
APPROVED      --VERIFY--> APPROVED       | 核验通过：学号/姓名与申请人一致
APPROVED      --HANDOVER--> COMPLETED    | 已核验学号，现场交接
```

> 这一段同时证明 **I7（交接前必须有核验通过流水）** 与 **VERIFY 是 APPROVED 自环、不改状态**。

## 6　结论

**终版结论（已执行回填）**：

本次针对契约 v1 的认领审核状态流原型完成了单元、集成、确认三层测试组织与执行：**24 项自动断言两次独立复现全部通过、失败 0 项**；核心状态机、RBAC 三角色越权拦截（40002）、身份核验 I7（40003）、超时批处理与审核流水可追溯性均得到验证；**C 端后台管理端（契约 #25–30）已在 FastAPI 原型内实现并验证**——`super001` 登录可见数据看板/用户管理/分类字典/地点字典/操作日志/CSV 导出，学生越权访问被 `40002` 拦截，管理员停自己被 `40003` 拦截，管理员权限最多得到实机佐证。
