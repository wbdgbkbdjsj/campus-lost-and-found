# 设计模型 04 — 时序图（审核通过主流程 + 退回补充分支）

## 4.1 主流程：提交 → 接单 → 通过 → 交接

```mermaid
sequenceDiagram
    autonumber
    actor U as 申请人
    actor A as 审核员(B端)
    participant C as ClaimAPI
    participant S as StateMachine
    participant D as DB
    participant N as Notify

    U->>C: POST /claims (found_item_id, proof)
    C->>D: insert claim(status=SUBMITTED)
    C->>D: insert review_record(null→SUBMITTED)
    C-->>U: 201 {id, status:SUBMITTED}

    A->>C: GET /review/queue
    C->>D: select claims where status=SUBMITTED order by submitted_at
    D-->>C: 列表
    C-->>A: 队列

    A->>C: POST /review/claims/{id}/accept
    C->>S: apply_transition(SUBMITTED, ACCEPT, actor=admin)
    S-->>C: UNDER_REVIEW (合法)
    C->>D: update claim.status, reviewer_id
    C->>D: insert review_record(SUBMITTED→UNDER_REVIEW)
    C-->>A: 200 {status:UNDER_REVIEW}

    A->>C: POST /review/claims/{id}/approve (comment)
    C->>S: apply_transition(UNDER_REVIEW, APPROVE, actor=reviewer)
    S-->>C: APPROVED
    C->>D: claim.status=APPROVED, deadline=+7d
    C->>D: found_item.status=PICKUP_PENDING
    C->>D: insert review_record
    C->>N: notify(申请人 审核通过)
    C-->>A: 200 {status:APPROVED}

    U->>C: 线下领取，出示学号
    A->>C: POST /review/claims/{id}/handover
    C->>S: apply_transition(APPROVED, HANDOVER, actor=reviewer)
    S-->>C: COMPLETED
    C->>D: claim.status=COMPLETED, found_item.status=CLAIMED
    C->>D: insert review_record
    C->>N: notify(双方 交接完成)
    C-->>A: 200 {status:COMPLETED}
```

## 4.2 分支：退回补充 → 申请人补充 → 重新审核

```mermaid
sequenceDiagram
    autonumber
    actor A as 审核员
    actor U as 申请人
    participant C as ClaimAPI
    participant S as StateMachine
    participant D as DB

    A->>C: POST /review/claims/{id}/request-info (comment必填)
    alt comment 为空
        C-->>A: 400 {code:40003}
    else comment 非空
        C->>S: apply_transition(UNDER_REVIEW, REQUEST_INFO)
        S-->>C: PENDING_INFO
        C->>D: status=PENDING_INFO, deadline=+7d
        C-->>A: 200
    end

    U->>C: POST /claims/{id}/supplement (proof)
    C->>S: apply_transition(PENDING_INFO, RESUBMIT, actor=applicant)
    S-->>C: UNDER_REVIEW
    C->>D: status=UNDER_REVIEW, proof 覆盖
    C-->>U: 200 {status:UNDER_REVIEW}
```

## 4.3 异常：非法迁移

```mermaid
sequenceDiagram
    actor A as 审核员
    participant C as ClaimAPI
    participant S as StateMachine

    A->>C: POST /review/claims/8/approve
    Note over C: claim#8 已 REJECTED(终态)
    C->>S: apply_transition(REJECTED, APPROVE)
    S-->>C: raise IllegalTransition
    C-->>A: 400 {code:40001, message:"ILLEGAL_TRANSITION",
                  detail:"REJECTED 不允许事件 APPROVE"}
```
