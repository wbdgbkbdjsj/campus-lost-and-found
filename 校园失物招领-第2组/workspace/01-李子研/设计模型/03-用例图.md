# 设计模型 03 — 用例图

```mermaid
flowchart LR
    subgraph 系统: 校园失物招领与认领审核系统
        UC1((注册/登录))
        UC2((发布失物启事))
        UC3((登记拾获物品))
        UC4((提交认领申请))
        UC5((补充凭证材料))
        UC6((撤销认领申请))
        UC7((查看审核队列))
        UC8((接单))
        UC9((审核通过/驳回))
        UC10((退回补充材料))
        UC11((确认交接完成))
        UC12((超时失效处理))
        UC13((查看通知/审核记录))
    end

    User([普通用户])
    Admin([审核员 B端])
    System([定时任务/系统])

    User --> UC1
    User --> UC2
    User --> UC3
    User --> UC4
    User --> UC5
    User --> UC6
    User --> UC13
    Admin --> UC1
    Admin --> UC7
    Admin --> UC8
    Admin --> UC9
    Admin --> UC10
    Admin --> UC11
    Admin --> UC13
    System --> UC12

    UC4 -.include.-> UC1
    UC9 -.extend.-> UC10 : 凭证不足时
```

说明：
- 普通用户核心用例：提交认领申请（UC4）→ 补充材料（UC5）/ 撤销（UC6）。
- 审核员（B 端，本模块）核心用例：队列（UC7）→ 接单（UC8）→ 通过/驳回（UC9）/ 退补（UC10）→ 交接（UC11）。
- 系统角色只做超时失效（UC12），对应 expire-run 接口。
