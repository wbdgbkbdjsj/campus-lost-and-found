# 接口文档 — 校园失物招领与认领审核系统 v1.1

> 依据 `api-contract-v1.md`（已重新冻结）。Base URL：`http://127.0.0.1:8000/api/v1`（原型）
> 统一返回：`{"code":0,"message":"ok","data":{}}`；失败 `{"code":40001,"message":"ILLEGAL_TRANSITION","detail":"..."}`
> 鉴权：除登录外均需 `Authorization: Bearer <token>`；角色三值：`student` / `reviewer` / `super_admin`
> 范围说明：本文细化 **A/B 端**（原型已实现 24 条）；C 端 6 条（契约 #25-30）为路径级约定，字段级定义由欧阳昊天补充分册。

## 0. 枚举速查

| claim.status | 中文 | 可执行事件 |
|---|---|---|
| SUBMITTED | 待审核 | ACCEPT(reviewer) / REJECT(reviewer) / CANCEL(本人) |
| UNDER_REVIEW | 审核中 | APPROVE / REJECT / REQUEST_INFO / CANCEL |
| PENDING_INFO | 待补充材料 | RESUBMIT(本人) / CANCEL / EXPIRE(系统) |
| APPROVED | 审核通过·待领取 | VERIFY(自环) / HANDOVER(需 I7) / EXPIRE(系统) |
| REJECTED / CANCELLED / COMPLETED / EXPIRED | 终态 | — |

角色速查：`student`=学生（A 端），`reviewer`=审核员（B 端），`super_admin`=超级管理员（C 端）。**`admin` 代号已废弃**。

## 1. 认证与通用（契约 #1-6）

### POST /auth/login
```json
// 请求
{ "student_no": "reviewer001", "password": "123456" }
// 响应 data
{ "token": "3f2a...",
  "user": { "id": 1, "student_no": "reviewer001", "name": "李子研", "role": "reviewer" } }
```
错误：40003 学号或口令错误；40002 账号已被停用（user.status=DISABLED）。

### GET /auth/me
data：`{ "id":1, "student_no":"...", "name":"...", "role":"reviewer" }`

### GET /dict/categories ｜ GET /dict/locations（全部角色）
data：`[ { "id": 1, "name": "证件" }, ... ]` / `[ { "id": 1, "name": "三教" }, ... ]`

### GET /notifications（全部角色）
data：`{ "total": 3, "items": [ { "id":21, "title":"认领审核通过", "content":"...", "is_read":false, "created_at":"..." } ] }`

## 3. 认领申请（A 端 + 共用，契约 #12-16）

### POST /claims
```json
{ "found_item_id": 12, "description": "11月1日上午在三教201丢的黑色长柄伞",
  "proof": "伞柄有一道白色划痕，伞骨内侧写有姓名缩写 WXM", "contact": "138****0000" }
```
响应 data：`{ "id":8, "status":"SUBMITTED", "allowed_events":[...] }`
前置校验：物品 status ∈ {REGISTERED, CLAIMING}；proof 必填；同一人同一物品不得有未终结单（均 40003）。成功后物品→CLAIMING。

### GET /claims?scope=mine ｜ GET /claims/{id}
- scope=mine 限本人；reviewer/super_admin 可看全部。
- 详情含完整流水：
```json
{ "id":8, "status":"APPROVED", "deadline":"2026-11-11 10:20:00",
  "records": [
    { "action":"ACCEPT", "from_status":"SUBMITTED", "to_status":"UNDER_REVIEW", "comment":"", "created_at":"..." },
    { "action":"APPROVE", "from_status":"UNDER_REVIEW", "to_status":"APPROVED", "comment":"凭证与物品一致", "created_at":"..." },
    { "action":"VERIFY", "from_status":"APPROVED", "to_status":"APPROVED", "comment":"核验通过：学号/姓名与申请人一致", "created_at":"..." }
  ] }
```

### POST /claims/{id}/supplement
`{ "proof": "补充特征..." }`；PENDING_INFO→UNDER_REVIEW；proof 空→40003；非本人→40002。

### POST /review/claims/{id}/cancel（申请人撤销）
仅本人；非终态→CANCELLED；APPROVED 撤销后物品回退 REGISTERED。

## 4. 审核 B 端（核心，契约 #17-24，均需 reviewer）

### GET /review/queue
data：`{ "total":2, "items":[ { "id":8, "title":"黑色雨伞", "applicant":"王小明", "status":"SUBMITTED", "submitted_at":"...", "waiting_minutes":35, "allowed_events":[...] } ] }`
排序：submitted_at 升序（先到先审）。

### POST /review/claims/{id}/accept
无 body。SUBMITTED→UNDER_REVIEW，锁定 reviewer_id。
| 错误 | 场景 |
|---|---|
| 40001 | 非 SUBMITTED（已被他人接单/终态） |
| 40002 | 非 reviewer |
| 40401 | 单据不存在 |

### POST /review/claims/{id}/verify   ★ v1 新增·身份核验（自环，不改状态）
```json
// 请求：到场人信息
{ "student_no": "stu001", "name": "王小明" }
// 响应 data（一致）
{ "verified": true, "comment": "核验通过：学号/姓名与申请人一致" }
// 响应 data（不一致，仍 200，但留档 + 通知申请人）
{ "verified": false, "comment": "核验不通过：到场人 stu009/路人 与申请人 stu001/王小明 不一致" }
```
约束：仅 APPROVED 状态（否则 40001）；仅接单审核员本人（40002）；学号姓名必填（40003）。verified=false 亦写入 VERIFY 流水，作为冒领未遂证据。

### POST /review/claims/{id}/approve
`{ "comment": "凭证与物品一致" }`；UNDER_REVIEW→APPROVED；物品→PICKUP_PENDING；deadline=+7d；通知申请人。
仅接单审核员本人（40002）。

### POST /review/claims/{id}/reject
`{ "comment": "凭证描述与物品明显不符" }` ← **comment 必填**（40003）；SUBMITTED/UNDER_REVIEW→REJECTED；物品回退 REGISTERED。

### POST /review/claims/{id}/request-info
`{ "comment": "请补充物品内部特征" }` ← **comment 必填**；UNDER_REVIEW→PENDING_INFO；deadline=+7d。

### POST /review/claims/{id}/handover
`{ "comment": "已核验学号，现场交接" }`
**前置（不变量 I7）**：本单必须存在"核验通过"的 VERIFY 流水，否则：
```json
{ "code": 40003, "message": "VALIDATION_ERROR",
  "detail": "交接前必须先通过身份核验（POST /review/claims/{id}/verify）" }
```
成功：APPROVED→COMPLETED；物品→CLAIMED；通知双方。

### POST /review/expire-run
`{ "now": "2026-11-20T00:00:00" }`（可选，便于测试）
data：`{ "expired": 2, "ids": [8, 9] }`；超期 PENDING_INFO/APPROVED→EXPIRED，APPROVED 超期物品回退 REGISTERED。

### 错误码总表（契约 §6）
| code | message | detail 示例 |
|---|---|---|
| 40001 | ILLEGAL_TRANSITION | COMPLETED(已完成) 为终态，不允许事件 APPROVE |
| 40002 | FORBIDDEN | 需要审核员(reviewer)权限 / 该单据已由审核员#2 接单 |
| 40003 | VALIDATION_ERROR | 交接前必须先通过身份核验 / 驳回必须填写原因 |
| 40401 | NOT_FOUND | claim#999 不存在 |
| 40101 | UNAUTHORIZED | token 无效或已过期 |

## 6. curl 快速验证（含负例）

```bash
TOKEN=$(curl -s -X POST http://127.0.0.1:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"student_no":"reviewer001","password":"123456"}' | python -c "import sys,json;print(json.load(sys.stdin)['data']['token'])")
AUTH="Authorization: Bearer $TOKEN"; CT="Content-Type: application/json"

curl -s http://127.0.0.1:8000/api/v1/review/queue -H "$AUTH"
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/accept   -H "$AUTH"
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/approve  -H "$AUTH" -H "$CT" -d '{"comment":"凭证一致"}'
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/handover -H "$AUTH"   # 40003 未核验
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/verify   -H "$AUTH" -H "$CT" -d '{"student_no":"stu001","name":"王小明"}'
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/handover -H "$AUTH"   # COMPLETED
curl -s -X POST http://127.0.0.1:8000/api/v1/review/claims/1/approve  -H "$AUTH"   # 40001 终态
curl -s -X POST http://127.0.0.1:8000/api/v1/review/expire-run        -H "$AUTH"
```
