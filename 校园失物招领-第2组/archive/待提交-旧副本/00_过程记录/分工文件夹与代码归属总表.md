## 8. 与上一轮「有无成型 C 端 / A-B 权限 web 端」的对应

- **C 端 exe 窗口端**：全组没有，且**不该有**。邓《技术选型》§6 定死「单前端工程 RBAC 三端」，C 端是 `/admin` 下的 Web 页面，不是桌面程序。骨架里 `views/admin/` 9 页占位 + `AdminLayout.vue` + `router/modules/admin.ts` 已建，但**业务代码未实现**（属欧阳昊天）。
- **A/B 端权限 web 端**：正式工程里是**四层隔离**（路由前缀 `/student` `/audit` `/admin` + `meta.roles` + `guards.ts` 守卫 + 后端 `@PreAuthorize`），邓《工程骨架说明》§4.3 明确「前端守卫只是体验，后端注解才是安全边界」。另有 `桌面/02-李子研/05_源码/` 可离线演示的三角色原型（内存 token，24/24 + 15/15 实测）。
- 两者都不等于「成型可交付」：正式工程目前是**可构建的骨架**，业务代码与 9 张表都还没填。
