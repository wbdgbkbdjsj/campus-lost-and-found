# 演示 exe 打包说明（免装 Python 现场跑）

## 目标
把 `src/lost-found-prototype/`（FastAPI 后端 + 零构建 Vue3 前端）打包成**单个 exe**，
答辩/演示现场只要双击就能起服务并自动打开浏览器，**无需安装 Python 与任何依赖**。

## 产出
- `dist/校园失物招领演示.exe` —— 单文件，约几十 MB，自带 Python 运行时与全部依赖。
- 启动后访问 `http://127.0.0.1:8000/`。
- 演示账号：`stu001` / `reviewer001` / `super001`（口令均为 `123456`），`super001` 可进 C 端后台管理页。

## 重新打包（如需在自己机器上构建）
1. 安装 Python 3.10+，并装 PyInstaller：
   ```bash
   python -m pip install pyinstaller
   ```
2. 在本目录双击 `build_exe.bat`，或在命令行执行同内容命令。
3. 产物在 `dist/校园失物招领演示.exe`。

## 现场使用要点
- 把 `校园失物招领演示.exe` 单独拷到任意可写目录（**不要放在 C:\Program Files 等受控目录**，否则数据库无法写入）。
- 双击 → 出现控制台窗口显示「服务启动中」→ 浏览器自动打开演示页。
- 关掉控制台窗口即停止服务；数据库 `lostfound.db` 会生成在 exe 同目录，二次启动沿用。
- 若 8000 端口被占用，临时改 `run_demo.py` 里的 `PORT` 再重打包即可。

## 已知注意
- 单文件 exe 首次启动会有 1~2 秒解压到临时目录的延迟，属正常。
- Windows SmartScreen / 杀软可能对 PyInstaller 打包程序报警，选择「仍要运行 / 允许」即可，源码透明可查。
- 数据库用 SQLite，演示环境即开即用；正式工程按组约定为 MySQL，二者通过 ORM 层解耦，切库只改连接串。
