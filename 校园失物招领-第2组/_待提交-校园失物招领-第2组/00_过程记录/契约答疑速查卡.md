## 3. 高频问答

**Q：B 端接口谁能调？**
A：只有 `reviewer`。学生和超管都会 40002。其中 accept 后，approve / verify / handover 仅限**接单本人**（reviewer_id 锁定）。

**Q：状态到底几个？撤销能撤哪些？**
A：8 态 12 条迁移 + 1 个 VERIFY 自环。CANCEL 只有三条边：SUBMITTED / UNDER_REVIEW / PENDING_INFO → CANCELLED；APPROVED 及四个终态不能撤（40001）。终态：REJECTED / CANCELLED / COMPLETED / EXPIRED。

**Q：核验失败算报错吗？**
A：不算。VERIFY 不改状态（from=to=APPROVED），一致返回 verified=true，不一致返回 verified=false 且**照常写流水**（冒领未遂证据）。两种结果都留痕，只有没核验就交接才 40003。

**Q：驳回/撤销/超时后物品怎么办？**
A：一律回退 `REGISTERED`，物品可被重新认领；通过时转 `PICKUP_PENDING` 防重复认领；交接完成转 `CLAIMED`。

**Q：错误码怎么对应？**
A：40001 非法状态迁移 / 40002 无权限 / 40003 参数校验（驳回原因、核验前置、proof 为空）/ 40401 资源不存在 / 40101 未登录。

**Q：技术栈到底算哪个？**
A：文档口径统一 **Vue3 + Spring Boot + MySQL**（全组约定）；FastAPI 版定位「审核状态流原型 + 演示保底」，单列附录 A。这份属于组长拍板范围，**别在材料里自行改成 Python**；有问题转组长。

**Q：FR 编号、术语条目解释找我吗？**
A：不找我。FR-01~16 与术语表 v1 都归阴亮；我只答契约（表 / 接口 / 状态机 / 角色代号 / 错误码）。
