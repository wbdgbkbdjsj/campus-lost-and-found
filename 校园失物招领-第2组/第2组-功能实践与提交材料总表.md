## 6 答辩三问·标准答法（务必本人过一遍）

**Q1｜「文档写 Spring Boot + MySQL，怎么演示跑的是 Python + SQLite？」**
> 三块源码各司其职：正式方案 Vue3 + Spring Boot 3 + MySQL 8 的工程骨架已经搭好（可编译，见 `lost-found-server/`），Vue 界面 25 页也已构建通过（见 `lost-found-web/`）；而业务接口最先跑通的是同构 FastAPI 原型 `05_源码/`，它把最难的审核状态流和 I7 防冒领规则验证透了，留下 24 项两次复现的测试证据。现场演示是**邓的 Vue 界面 +  FastAPI 业务后端**，Spring Boot 侧构件一一对应（service↔review-module、state_machine↔状态机、main↔Controller、models↔实体），属于工程化平移范围，不是两套设计、也不是没做。

**Q2｜「A/B/C 三端都做完了吗？C 端呢？」**
> 三端界面都做出来了（学生端 8 页、审核端 6 页、后台端 9 页），业务上跑通的是 A 端基础接口 + B 端审核状态流 —— 这是课题「认领审核」的核心；C 端 #25–30 的接口在契约里定义完整，原型目前只做到 `super_admin` 登录，页面是占位/只读，没有造假数据。我们选择先把核心状态机与防冒领规则做实做透，而不是三端都做半成品。

**Q3｜「代码规模够吗？」**
> 不拿规模硬凑。可运行业务部分覆盖 9 张表、24 条路由、8 态 12 迁移和全部关键不变量，24 项断言两次独立复跑全绿；前端 25 页 Vue 工程与 Spring Boot 骨架也都可构建/可编译。未完成的是 C 端业务接口与 MySQL 迁移，已如实写进材料边界，不宣称完成。
